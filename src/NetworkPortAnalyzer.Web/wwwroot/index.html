Setup required

Set up port capture

Install Npcap to let JackPeek listen for switch advertisements on your wired adapter.

  1. Download NpcapOpen the official Nmap project website.
  2. Install with approvalUse your organization's approved installer settings.
  3. Check your connectionSelect Check again, or restart JackPeek after installation.

Npcap is installed separately. JackPeek does not bundle it or install it silently.
