Capture driver required

JackPeek can see the wired adapter, but Windows has not exposed an Npcap capture device for it.

  1. Download Npcap from the official Nmap project website.
  2. Run the installer using your organization approved settings.
  3. Restart JackPeek or choose Check again after installation.

JackPeek does not bundle, redistribute, or silently install Npcap.
